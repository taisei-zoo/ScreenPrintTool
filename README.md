# ScreenPrintTool

**ScreenPrintTool** は Windows 環境向けに開発されたスクリーンショット印刷・保存ツールです。マルチモニター環境やディスプレイ複製・拡張時も、ディスプレイ番号を指定することで必要な画面だけを印刷・保存できます。ショートカットキーを押すだけでキャプチャ、印刷、保存、ペイント貼り付けまで自動で行います。

全てにおいて初心者の作成者がお勉強のために ChatGPT を活用して作成しています。機能要望や改善要望があればお願いします。

---

## 対応環境

- **対応OS**: Windows 10 / 11
- **開発 Python バージョン**: 3.13
- **動作確認済プリンター**: Microsoft Print to PDF、DocuPrint など

---

## 主な特徴（v1.2.6）

- **ショートカットキー対応（8種）**  
  PrintScreen や Alt+F12 などから選択可能。新しいショートカットキー候補も募集中。
- **保存モード選択可能**  
  「印刷のみ」「保存のみ」「印刷・保存」の 3 つから選べます。
- **画像保存先は `ユーザー¥ピクチャ¥ScreenPrintTool`**  
  トレイアイコンの「スクショ保存先を開く」からエクスプローラーを起動できます。
- **A4 印刷対応**  
  ワイド画面も A4 縦に自動調整して印刷（A4 横は動作検証中）。
- **タスクバー除外キャプチャ**  
  撮影範囲からタスクバーを除外可能（実験的機能）。
- **スクリーンショットの自動削除**  
  保存日数を指定して古い画像を起動時に自動削除（初期値 10 日）。
- **ペイント自動起動＆貼り付け**  
  撮影後に自動でペイントを開き、画像を貼り付け。
- **Snipping Tool との競合防止**  
  PrintScreen キーとの干渉を防止するレジストリ変更機能あり。
- **クリップボードへの自動コピー**  
  撮影した画像は常にクリップボードにも保存されます。

## セットアップ方法

### Python 実行版

1. リポジトリをクローンするか ZIP を展開  
2. Python 環境で必要ライブラリをインストール

```bash
pip install -r requirements.txt
```

### exe 実行版 (Python 環境不要)

1. `ScreenPrintTool_V1.2.6.zip` を解凍  
2. `SPTsetup_admin.bat` を **管理者として実行**  
   スタートアップ登録後、次回ログオン時から自動起動します。手動起動する場合は次の手順へ。
3. `SPTstart_user.bat` をユーザー権限で実行
