# ScreenPrintTool

**ScreenPrintTool** は、Windows 環境向けに開発されたスクリーンショット印刷＆保存ツールです。 
マルチモニター、マルチディスプレイ(複製・拡張)の場合でも、ディスプレイ番号を指定することで、必要なディスプレイのみを印刷＆保存できます。
ショートカットキーを押すことで、画面を即座にキャプチャし、印刷・保存・ペイント貼り付けを自動で行います。

全てにおいて初心者の作成者がお勉強のため、ChatGPT活用にて作成しています。
機能要望や改善要望があればお願いします。

##  対応環境

- **対応OS**：Windows 10 / 11
- **開発Pythonバージョン**：3.13
- **動作確認済プリンター**：Microsoft Print to PDF、DocuPrintなど

---

##  主な特徴（v1.2.6）

- **ショートカットキー対応（8種）**  
  PrintScreen や Alt+F12 などから選択可能（新しいショートカットキー候補募集中
- **保存モードを選択可能**  
  「印刷のみ」「保存のみ」「印刷・保存」の3通りに対応
- **画像は「ユーザー¥ピクチャ¥ScreenPrintTool」に保存**
  トレイアイコンを右クリックし、「スクショ保存先を開く」からエクスプローラーを起動可能
- **A4印刷に対応**  
  ワイド画面もA4縦に自動調整して印刷可能（A4横は動作検証中）
- **タスクバー（下部）除外キャプチャ**  
  撮影範囲からタスクバーを除くことが可能（実験的機能）
- **スクリーンショットの自動削除機能**  
  保存日数（初期値10日）を指定して、古い画像を起動時に自動削除
- **ペイント自動起動＆貼り付け機能**  
  撮影後、自動的にペイントを起動し、画像を貼り付け
- **Snipping Toolとの競合防止**  
  PrintScreenキーとの干渉を防止（レジストリ変更機能あり）
- **クリップボードへの自動コピー**  
  撮影した画像は常にクリップボードにも保存されます

##  セットアップ方法（Python 実行版）

1. このリポジトリをクローン or ZIPダウンロード
2. Python環境で必要ライブラリをインストール

```bash
pip install -r requirements.txt
```

##  セットアップ方法（exe実行版_Python環境不要）
1. ScreenPrintTool_V1.2.6.zipを解答
2. SPTsetup_admin.batを管理者として実行
   スタートアップに登録するため、次回ログオン時に自動起動。
   手動起動する場合は、次を実行
3. SPTstart_user.batをユーザー権限で実行

## 今後の実装予定機能

以下の機能は、今後のバージョンアップで追加・改善を予定している内容です：

- [ ] **キャプチャ画像へのメタ情報の表示機能**  
      印刷日時やユーザー名などをスクリーンショットに自動的に埋め込む機能。表示ON/OFFも選択可能。
