# ScreenPrintTool

**ScreenPrintTool** は、Windows 環境向けに開発された  
**スクリーンショットの取得・印刷・保存をワンアクションで実行する業務効率化ツール**です。

ショートカットキーを押すだけで、

- 画面キャプチャ
- クリップボードコピー
- 印刷 / 保存
- ペイント / フォト表示

を自動で実行し、  
日常業務におけるスクリーンショット作業を大幅に効率化します。

マルチモニター・マルチディスプレイ（複製 / 拡張）環境にも対応しており、  
ディスプレイ番号を指定することで、**必要な画面のみを正確に処理可能**です。

機能要望や改善要望があれば歓迎します。

## 想定用途
- 業務画面をすばやく印刷したい
- スクリーンショットを即保存したい
- コピー＆貼り付けの手間を減らしたい
- Print Screen キーだけで処理を完結させたい

## 主な特徴（v1.3.5）

- **ショートカットキー対応（複数パターン）**
  - PrintScreen / Ctrl+Alt+P などから選択可能
- **保存モード切替**
  - 印刷のみ / 保存のみ / 印刷＋保存
- **ディスプレイ指定キャプチャ**
  - マルチモニター環境に対応
- **印刷方向自動判定**
  - 画面に応じてA4縦・横を自動切替
- **クリップボード自動コピー**
  - 常に画像を即利用可能
- **保存後にアプリ起動**
  - 保存した画像をすぐに確認したい場合、ペイント / フォトで自動表示が可能
- **タスクバー除外キャプチャ（任意）**
  - 隠したい情報が表示されている場合に使用できる機能。検証中の部分あり  
- **古い画像の自動削除**
  - 保存日数を指定可能（初期10日）
  - 画像名で判断し、ツール起動時に保存日数経過のファイルを自動削除
- **Snipping Toolとの競合回避**
  - PrintScreenキーで Snipping Tooを立ち上げるレジストリの編集機能
  - 設定に応じに本ツールの起動ショートカットを別パターンにするなどして使い分けを想定
- **印刷情報の可視化（ウォーターマーク）**
  - 印刷時に、「取得日時（日時・時刻）」「実行ユーザー（表示名＋ログインID）」を印刷物へ自動付加します。
  - 出力日時の明確化、実行者の特定、印刷物の管理性向上を図ります。必要に応じて「取扱注意」「持出厳禁」などの強い注意喚起文言を表示することも可能
- **印刷中ポップアップ表示**
- **タスクトレイ常駐**

##  セットアップ方法（Python 実行版）

1. このリポジトリをクローン or ZIPダウンロード
2. Python環境で必要ライブラリをインストール

```
pip install -r requirements.txt
```

##  セットアップ方法（標準版配布用_Python環境不要）
1. ScreenPrintTool_V1.3.5.zipを解凍
2. SPTsetup_admin.batを管理者として実行
   スタートアップに登録するため、次回ログオン時に自動起動。
   即時手動起動する場合は、次を実行
3. SPTstart_user.batをユーザー権限で実行
